# Setup Guide

## Prerequisites

1. **Python 3.8 or higher** installed on your system
2. **FFmpeg** for audio/video processing
3. **Git** for cloning the repository (optional)

## Installation Steps

### 1. Clone the Repository

```bash
git clone <repository-url>
cd ott-speech-detection
```

Or download and extract the ZIP file if you don't have Git installed.

### 2. Install FFmpeg

#### Windows:
1. Download FFmpeg from https://ffmpeg.org/download.html
2. Extract the archive
3. Add the `bin` folder to your system PATH

#### macOS:
```bash
brew install ffmpeg
```

#### Linux (Ubuntu/Debian):
```bash
sudo apt update
sudo apt install ffmpeg
```

### 3. Create a Virtual Environment (Recommended)

```bash
python -m venv venv
```

#### Windows:
```bash
venv\Scripts\activate
```

#### macOS/Linux:
```bash
source venv/bin/activate
```

### 4. Install Python Dependencies

```bash
pip install -r requirements.txt
```

Note: Some packages may take a while to install, especially PyTorch and Transformers.

### 5. Install Optional Dependencies

If you want full audio conversion support, you can try installing pydub (note that it may not work with Python 3.13+):

```bash
pip install pydub
```

### 6. Configure Environment Variables (Optional)

For Azure Translator services, set these environment variables:

#### Windows:
```cmd
set AZURE_TRANSLATOR_KEY=your_key_here
set AZURE_TRANSLATOR_REGION=your_region_here
```

#### macOS/Linux:
```bash
export AZURE_TRANSLATOR_KEY=your_key_here
export AZURE_TRANSLATOR_REGION=your_region_here
```

### 7. Run the Application

```bash
python app.py
```

The application will start on `http://localhost:5000`

## Troubleshooting

### Common Issues

1. **"No module named 'whisper'"**: Make sure you installed the requirements.txt file
2. **FFmpeg not found**: Ensure FFmpeg is installed and added to your PATH
3. **Port already in use**: Change the port in app.py or stop the process using that port
4. **CUDA out of memory**: The application will automatically use CPU if GPU memory is insufficient

### Windows-Specific Issues

1. **"&&" token error**: Use `;` instead of `&&` in PowerShell commands
2. **Execution policy errors**: Run PowerShell as administrator and execute:
   ```powershell
   Set-ExecutionPolicy RemoteSigned
   ```

## Using the Application

1. Open your web browser and go to `http://localhost:5000`
2. Select your input method:
   - **Microphone**: Click "Start Recording" to record live speech
   - **Audio File**: Upload one or more audio files
   - **Video File**: Upload one or more video files
   - **YouTube**: Paste a YouTube URL
3. Select source and target languages
4. Adjust audio quality settings if needed
5. Enable advanced options like formality and profanity filtering
6. Click "Translate Speech" to process

## Features Overview

### Real-time Translation
- Record live speech and get instant translation
- Enable streaming for continuous translation

### Batch Processing
- Upload multiple files for simultaneous processing
- Faster processing with concurrent multi-threading

### Quality Options
- Choose sample rate (8000 to 44100 Hz)
- Select mono or stereo channels

### Advanced Translation
- Formality control (formal/informal/default)
- Profanity filtering options
- Automatic language detection

### History and Favorites
- View past translations
- Save favorite translations
- Clear history when needed
